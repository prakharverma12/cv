# AI / ML Engineer

We are hiring an AI/ML Engineer to build and ship LLM-powered products. You will
design agentic systems, integrate foundation models, and take features from
prototype to production.

## Responsibilities
- Build LLM applications: agents, tool-use / function-calling, RAG, prompt orchestration.
- Integrate foundation models (Amazon Bedrock, OpenAI, Gemini, Sarvam or similar) into product workflows.
- Design multi-agent and intent-routing pipelines; optimize latency and token cost.
- Build evaluation harnesses (precision/recall/F1) to benchmark model outputs.
- Ship on cloud infrastructure (AWS Lambda, SQS, EventBridge, S3) with observability.

## Required
- Strong Python (and one of Java / C++ / JavaScript).
- Hands-on with LLM APIs, prompt engineering, and at least one agent framework.
- Cloud experience: AWS (Lambda, S3, queues) or equivalent.
- Databases: PostgreSQL / DynamoDB / a vector store.
- Experience taking an AI feature to production with measurable impact.

## Nice to have
- PyTorch / Hugging Face, fine-tuning or embeddings work.
- Multimodal (vision / speech-to-text / OCR).
- Docker, Kubernetes, CI/CD.
- Guardrails / PII handling / compliance (DPDP, GDPR).
