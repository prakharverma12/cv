# Backend Engineer

We are looking for a Backend Engineer to design and operate scalable services and
data pipelines. You will own APIs, queues, and databases in production.

## Responsibilities
- Design, build, and maintain backend services and REST APIs.
- Build asynchronous, event-driven pipelines (producer/consumer, queues, batching).
- Optimize performance: latency, throughput, timeouts, database query tuning.
- Operate cloud infrastructure and ensure reliability, monitoring, and cost control.

## Required
- Strong programming in Java, Python, or C++.
- Cloud: AWS (Lambda, EventBridge, SQS, S3) or GCP/Azure equivalents.
- Relational databases (PostgreSQL, Aurora, RDS) and SQL query optimization.
- NoSQL (DynamoDB, MongoDB) and caching.
- REST API design; experience with concurrency and distributed systems.
- Git, Linux, testing, and CI/CD.

## Nice to have
- Message queues and idempotent / SKIP LOCKED batch processing.
- Docker, Kubernetes, Terraform / IaC.
- Observability (metrics, tracing, logging).
- React or another frontend framework for full-stack work.
