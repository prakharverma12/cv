# Data Scientist

We are hiring a Data Scientist to turn data into decisions — modeling, experimentation,
and clear communication of results to stakeholders.

## Responsibilities
- Build predictive and statistical models (regression, classification, clustering).
- Design and analyze experiments (A/B tests, causal inference).
- Wrangle and analyze large datasets; build data pipelines.
- Communicate findings with visualizations and written analysis to non-technical stakeholders.

## Required
- Strong Python and the data stack: NumPy, Pandas, Scikit-Learn, Matplotlib.
- Statistics: hypothesis testing, regression, experimentation.
- SQL and working with relational / NoSQL databases.
- Machine learning fundamentals: feature engineering, model evaluation, cross-validation.
- Clear data storytelling and visualization.

## Nice to have
- Deep learning (PyTorch), NLP.
- Cloud data tooling (AWS, warehouses).
- Dashboarding / BI tools.
- Domain experience in healthcare, finance, or travel.
