# ML / Research Engineer

We are seeking an ML Research Engineer to run large-scale training experiments and
push model quality on hard NLP problems. You will own the experiment lifecycle end
to end: data, training, evaluation, and reproducibility.

## Responsibilities
- Design and run training/eval pipelines for transformer models (BERT, T5, LLMs).
- Improve model quality on challenging tasks (long-tail, extreme multi-label / XMC, retrieval).
- Orchestrate large-scale distributed training on GPU clusters.
- Build reproducible experiment tooling and rigorous evaluation (F1, precision/recall).
- Read, reproduce, and extend recent research; publish or present results.

## Required
- Strong Python and PyTorch.
- Hugging Face Transformers; experience fine-tuning BERT/T5-class models.
- Distributed training on GPUs (SLURM, DGX, multi-node) and Linux.
- Solid grasp of NLP, in-context learning, and evaluation methodology.
- Ability to run controlled, reproducible experiments at scale.

## Nice to have
- Publications, posters, or competition results.
- Experience with XMC, retrieval, or long-tail label distributions.
- Data structures & algorithms depth; strong math foundation.
- Mixed-precision / quantization (INT8/FP16), throughput optimization.
